# P6: Hadamard time-encoded labeling, Look-Locker readouts and multi-TE ASL — implementation plan

**Goal:** Implement the P6 addendum (`docs/specs/2026-10-05-p6-encoding-design.md`): multi-TE
with the `echo-N` layout (part C), Hadamard time-encoded (P)CASL with a decoded main dataset and the
raw series under `sourcedata` (part A), and Look-Locker readouts for 2D EPI (part B), across
`mrsim-acq` and `aslscan`, with every existing output byte-identical. Velocity-selective labeling is
out (deferred by the addendum).

**Architecture:** Baselines first: the aslscan regression gate gains P5 cases (it has none) and is
re-pointed at `p5-complete`, shown to pass and to detect a change before any P6 change. Then
`mrsim-acq`'s one change (the per-volume closure moved into a private two-seed function, then the
new `simulate_acquisition_echoes`), because multi-TE needs it. Then aslscan's **schedule**
(preparation, raw volume, output volume) with explicit legacy dispatch, which all three parts build
on. Then the three parts as milestones, in increasing order of new physics: multi-TE (milestone M,
acquisition plumbing and outputs only), Hadamard (milestone H, kinetics reuse, decoding, a second
output tree), Look-Locker (milestone L, a new kinetic function and a generalized timeline). Each
milestone ends with its acceptance and the gates.

**Spec:** the P6 addendum, Codex-reviewed twice (2026-10-05) before this plan; the main spec and
the P2-P5 addenda where it is silent. P5 is complete at tag `p5-complete` in both repositories
(`aslscan` `715bcb0`, `mrsim-acq` `b340133`); TRXScan's consumer branch `p0-mrsim-acq-extraction` is
published at `12a9d09`.

## Task 1: `mrsim-acq` — the two-seed per-volume function and `simulate_acquisition_echoes`

1. Move the per-volume closure of `simulate_acquisition_oversampled` (`kspace.rs:1460-1530`) into a
   private `fn acquire_volumes(.., excitation_seed: u64, receiver_seed: u64)`: `excitation_seed`
   goes to `PrepPhase::shot` (`:1480-1482`); `receiver_seed` to `slice_seed` (`:1485-1489`) and to
   the image-space noise stream (`:1512-1521`). `simulate_acquisition_oversampled` calls it with
   both equal to `seed`. Same expressions, same order. Gates: golden record, bit-pinned tests,
   TRXScan P0, regress (all must be identical; this is the refactor that would move bits if wrong).
2. `pub fn simulate_acquisition_echoes(sim_dims, acq_dims, n_volumes, images_per_echo: &[&[Vec<f32>]],
   t2, fmap, t_inhom, acq, echo_times_ms, eddy_drive, prep_drive, phase, seed, noise_sigma,
   eddy_trace) -> Vec<(Vec<f32>, Vec<f32>)>`: per echo `e`, validate the timing with
   `Acquisition { t_echo: echo_times_ms[e], ..acq.clone() }` and call `acquire_volumes` with
   `excitation_seed = seed`, `receiver_seed = seed ^ echo_salt(e)`, `echo_salt(0) = 0`,
   `echo_salt(e) = (e as u64).wrapping_mul(0xD1B5_4A32_D192_ED03)` for `e > 0`.

Tests (through the wrapper, not by hand-built `SliceInput`s, so the wiring itself is tested):
- one echo at `acq.t_echo` equals `simulate_acquisition_oversampled` bit for bit, both feature sets,
  with k-space noise, `noise_sigma`, spikes, and a prepared phase model with non-`None` `prep_drive`;
- two echoes: echo 0 bit-identical to the single call; echo 1 equals a single call at `TE_1` with
  noise off (complex compare: magnitude and phase);
- noise channels separately, through the wrapper's outputs: k-space noise alone (`noise_variance > 0`,
  `noise_sigma` `None`) and image-space noise alone (`noise_variance = 0`, `noise_sigma` set), each
  run noise-on minus noise-off per echo, the two echoes' noise residuals (complex) uncorrelated
  (`|r| < 3/sqrt(n)`); and identical when the two echo times are equal and the salt is forced to
  zero (the negative control);
- shot phase shared: prepared phase on, noise off, no fieldmap, spin echo, one uniform compartment:
  echo 1 equals echo 0 times `exp(-dTE/T2)` (complex, to `4 * 2^-24` relative); the negative control
  calls `acquire_volumes` directly (a private function, from the unit test in the same module) with
  the excitation seed salted, and must fail the comparison. No public switch.
- the golden record and every bit-pinned test unchanged.

- [ ] Step 1, gates clean; commit (`mrsim-acq`): `refactor: per-volume acquisition takes two seeds`.
- [ ] Step 2 and tests, gates clean; commit (`mrsim-acq`): `feat: simulate_acquisition_echoes`.

## Task 2: `aslscan` — the schedule and legacy dispatch

**Index domains** (the contract every later task uses):

- `Protocol.rows` stays the **input/output rows**: what `aslcontext.tsv` lists and what is written
  (decoded rows under Hadamard, readout volumes under Look-Locker, the same rows for every echo).
  Legacy code keeps reading it unchanged.
- `Schedule.raw_rows: Vec<Row>`: one per **raw volume** (the acquisition call's volume index),
  with its own `t`, `tau`, `tr`, kind (`RowKind::Encoded` under Hadamard).
- `Schedule.preps: Vec<Preparation { raw, shot, start_s, labeling_window: [s, s], suppression: usize,
  venc: Option<f64> }>`: one per labeling; `raw` maps it to its raw volume (several per raw volume in
  3D; several raw volumes per preparation under Look-Locker via `RawVolume::prep`).
- `Schedule.raws: Vec<RawVolume { prep: usize (first), n_preps, readout: usize, cycle: Option<usize> }>`
  and `Schedule.outputs: Vec<Output::Raw(usize) | Output::Decoded { cycle, subbolus }>`;
  `Schedule.cycles` (Hadamard: the raw range and the matrix row per raw; Look-Locker: the raw range
  and the readout times and flips).
- Suppression pulse sets and VENC are resolved **per preparation** (indices into the existing
  `SuppressionSpec.per_row` sets, built per cycle under P6).
- The separate M0 stays outside the schedule (its own call, as today).

`Schedule::identity(&Protocol)` builds the layout of today's rows (one preparation per 2D row,
`NumberShots` per 3D row, the clock of `protocol.rs:1898-1909`). **Activation** is decided once:
`Protocol.p6_active = hadamard.is_some() || look_locker || echo_times_s.len() > 1`.
`series::simulate_core` checks it first: false calls today's body, moved verbatim into
`simulate_legacy` (no edit inside it; the move is the only change). True calls `simulate_p6`, which
Task 2 creates as a skeleton (an error naming the unimplemented feature) and Tasks 4, 9, 11 and 15
fill; the row-indexed helpers it needs (physiology windows and horizon, `series.rs:371-393`;
suppression per row; motion counts; the 3D line weights and shot sets) are given schedule-indexed
twins in those tasks, never edited in place. Separately, inside `simulate_p6`, one echo selects the
existing acquisition function and several select `simulate_acquisition_echoes`; Look-Locker's
scalar-flip one-readout case is a third, separate dispatch (Task 13).

Tests: an explicit **manifest** of legacy combinations (sidecar, context, overlay, phantom or crop,
geometry: every regress case, every end-to-end protocol builder, the P5 acceptance overlays with
their phantoms) parses, has `p6_active` false, and its identity schedule has one preparation per

## Milestone M: multi-TE

### Task 3: `aslscan` — protocol: echoes, sidecar agreement, timing

- CLI `--asl-json` becomes repeatable (`Vec<PathBuf>`); `protocol::load_with` takes a slice; one path
  is today's call. With several: each sidecar has a scalar `EchoTime` (an array is today's rule, the
  message now naming `echo-N`), strictly increasing; every other key equal across sidecars
  (`same_number` semantics, the first difference named with both values); `echo_times_s: Vec<f64>`
  on `Protocol` (one entry for a single echo).
- `[multi_te] refocusing_time` (ms, default 2; spin echo only; refused with one echo and under
  gradient echo); `[multi_te] max_image_memory_gib` (default 4; compat only).
- Timing (`protocol.rs`, a new `pub fn check_excitation_timing(p, acq_dims, excitations)`, all in
  seconds): the half EPI block is computed in aslscan as `h = ny * t_line / 2` (the same quantity as
  `mrsim-acq`'s private `SingleShotEpi::half_read_time`, `readout.rs:40-42`: `kx_max * ky_max * dt / 2`
  with `dt = t_line / kx_max`), with `t_line = TotalReadoutTime / ny` as `Protocol::acquisition`
  forms it (`protocol.rs:2139`); so it needs the acquired matrix and runs where the grid is known
  (`series` after the grid, and the CLI before writing), like `resolve_readout`. Excitation times
  are absolute within the repetition: `exc = row.t + offset_z` for an ASL row, `offset_z` for an
  `m0scan` row and the separate M0 (zero-relative), `t_n + offset_z` for a Look-Locker readout
  (Task 14). Excitation groups from the offsets (sorted, equal offsets one group, multiband groups at
  `protocol.rs:1137`); within an excitation the sampled blocks `[exc + TE_e - h, exc + TE_e + h]`,
  gradient echo non-overlapping, spin echo with pulses at `TE_1/2` and `(TE_e + TE_{e+1})/2`
  reserving `refocusing_time`; between groups the last block before the next group's excitation;
  the last group's last block before `TR`; under compat the between-group checks waived (recorded).
  Refusals: multi-TE with 3D, with Look-Locker; compat with a separate M0 (unchanged).

Tests: agreement (each key class: number, array, string, object; numeric `60` vs `60.0` equal);
`EchoTime` order; every timing rule accept/reject (gradient and spin echo; multiband groups;
interleaved and reversed orders; compat waiver; **an excitation that fits in `TR` whose last echo
does not**, rejected); `h` against `SingleShotEpi` built the way `mrsim-acq` builds it, equal to the
bit; the refusals; one sidecar parses as today.

- [ ] Implement and test; commit (`aslscan`): `feat: multi-TE protocols`.
